## Lessons to keep

When a function returns `Option` or `Result`, write `?` or `let Some(value) = expr else { return ... };`.
Do not match `Ok` and `Err` by hand when `?` does the same job.

Where a nested condition is likely, the packet shows the collapsed `if a && b` form, or one `if else if`.
Do not nest an `if` inside an `if`.
