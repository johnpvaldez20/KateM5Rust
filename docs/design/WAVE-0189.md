## Lessons to keep

When a function returns `Option` or `Result`, write `?` or `let Some(value) = expr else { return ... };`.
Do not match `Ok` and `Err` by hand when `?` does the same job.

`clippy::collapsible_if` rewrites `if a { if b { ... } }` into `if a && b`.
Where a nested condition is likely, the packet shows the collapsed `if a && b` form, or one `if else if`.
Do not nest an `if` inside an `if`.

Trim spaces and tabs with `[' ', '\t']`.
Do not write a hand-made test that compares a character with a space and then a tab.
`clippy::manual_pattern_char_comparison` is that lint.
PKT-0153 hit it.

When two arms return the same value, write one condition with `||`.
Do not write `if a { value } else if b { value }`.
`clippy::if_same_then_else` is that lint.
PKT-0177 hit it.

When a packet changes a documented rule, update the doc comment that states the old rule.
You may update an existing test that asserts the old rule.
The packet names those tests.
Do not rewrite a test the packet says must stay green.
Run the full test module, not only the new test.
PKT-0159 and PKT-0170 are the lesson.

Each packet lists the nearby functions that stay unchanged.
Do not edit a function on that list.
