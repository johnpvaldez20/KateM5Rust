## Lessons to keep

When a function returns `Option` or `Result`, write `?` or `let Some(value) = expr else { return ... };`.
Do not match `Ok` and `Err` by hand when `?` does the same job.

`clippy::collapsible_if` rewrites `if a { if b { ... } }` into `if a && b`.
Do not nest an `if` inside an `if`.

When two arms return the same value, write one condition with `||`.
`clippy::if_same_then_else` is that lint.

A helper with no caller outside tests needs `#[cfg_attr(not(test), allow(dead_code))]` when it is not a public item of a public type.

Each packet lists the nearby functions that stay unchanged.
